LLM Tags

Tags are resolved once and delivered to every enabled target. Editing here changes one session: the entry is written to that session's own overrides.toml and the global settings are left alone.

Tags

A value is sent as a string. Leave it empty for a marker (true). Use the CLI for a typed value: aoe-llm-tags tag --set 'cost:=1.5'.

Token

Replaces what a target with no template renders — the JSON payload or the csv list, depending on the target. A target with its own template ({session_id}) is unaffected.
