Harness extensions

A harness that loads code from its config directory can report a change on its next request instead of at the next launch. To do that this plugin installs a small set of files inside that harness's session config — the hook itself, a skill that keeps the session's activity current, and a one-line reminder — plus that skill in AoE's own skill list, and only after you approve the exact set below. Nothing is installed by default, and every harness that has no such hook keeps to launch-time tags.
