LLM Tags

This page is the session's detail view. The LLM Tags panel on the right has three tabs — this session, its project and AoE — and the JSON editor below writes to the level you choose. The token stays in this session's file and is never published.

Token

Replaces what a target with no template renders — the JSON payload or the csv list, depending on the target. A target with its own template ({session_id}) is unaffected. Once saved the value is not shown again on this page: the session file holds it and aoe-llm-tags tag --show reads it.

Harness extensions

    

      

        A harness that loads code from its config directory can report a change on its
        next request instead of at the next launch. To do that this plugin installs a small
        set of files inside that harness's session config — the hook itself, a skill that keeps the
        session's activity current, and a one-line reminder — plus that skill in AoE's own skill
        list, and only after you approve the exact set below. Nothing is installed by default, and
        every harness that has no such hook keeps to launch-time tags.
